# Worked example: from input to recommendation

Generated by `python -m notebooks.phase5_walkthrough` from the data and `config.yaml`;
re-running it gives the same numbers. Example: **A: $10,000, medium risk**, as of **2026-08-31**.

## 1. Input

The user gives two things: **$10,000** and risk tolerance **medium**. The
risk tolerance sets the risk-aversion parameter **γ = 5** (low / medium / high = 10 / 5 / 2).
Everything else is fixed by the project, not chosen by the user (advisor feedback A4):
the 51-stock universe, long-only, at most **10% per stock**, and the sector rule,
**no sector above 25%**, the same constraints the backtest uses.

## 2. Data as of 2026-08-31

Only data dated on or before 2026-08-31 is used (tested by scrambling everything after it).
Σ is the sample covariance of the last 252 trading days
of daily returns, scaled to a month. The risk-free rate is 3.73% a year.

## 3. ML forecasts (the views Q)

The Phase 4 headline model, the elastic net, is retrained with the Phase 3 walk-forward
on data up to 2026-08-31 and forecasts each stock's next-month excess return. The
forecasts range from 0.80% to 1.51% a month
(51 distinct values across 51 stocks).

## 4. Black–Litterman: prior, view uncertainty, posterior

- **Prior Π = δΣw_mkt** (δ = 2.5): the returns that make today's market-cap weights optimal.
- **View uncertainty Ω-A**: each stock's mean squared past forecast error (last
  24 months), shrunk toward its return variance. Large Ω = little trust.
- **Posterior μ_BL** (T6), τ = 0.05: μ_BL moved **31%** of the way from the
  prior toward the views (‖μ_BL − Π‖ / ‖Q − Π‖), so the weak forecasts change little.

## 5. Optimization

maximize μ_BLᵀw − (γ/2)wᵀΣw subject to 1ᵀw = 1, 0 ≤ wᵢ ≤ 10%, every sector ≤ 25%.

- Solver status **optimal**; **49 stocks** in the target portfolio.
- At the 10% stock cap: none.
- Sectors at the 25% cap: none (largest sector:
  Information Technology, 23.3%).
- KKT check (T4), largest violation: stationarity 4.4e-18, primal
  2.2e-16, dual 0.0e+00, complementarity 3.0e-10,
  so the solution is the certified optimum.
